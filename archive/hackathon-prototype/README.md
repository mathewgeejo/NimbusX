# Archived hackathon prototype

This directory preserves the pre-NimbusX implementation for historical reference only.

It is **not part of the application**, is not tested, and must not be deployed.  In
particular, the prior prototype used synthetic/fallback values, uncalibrated
probabilities, and Gemini-oriented modules that violate NimbusX's evidence-first
data policy.

The supported product lives in `backend/nimbusx`, `frontend/src`, `deploy`, and
`docs` at the repository root.  Git history remains the source of record for the
exact migration history.
